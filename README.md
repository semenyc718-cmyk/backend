# Описание проекта
 API для работы с коллекцией фильмов. С помощью приложения можно добавлять фильмы в базу данных, просматривать сохранённые записи, изменять информацию о фильмах и удалять их.

 используемые технологии

Python - язык программирования
FastAPI для создание API и обработка HTTP-запросов
SQLAlchemy для работы с базой данных
Pydantic для проверки и обработка данных
SQLite для хранения информации о фильмах
Alembic  для  управления миграциями базы данных

# Эндпоинты


GET

/movies/

Получение списка фильмов


POST

/movies/

Добавление нового фильма


GET

/movies/{movie_id}

Получение фильма по его ID


PUT

/movies/{movie_id}

Изменение информации о фильме



DELETE

/movies/{movie_id}

Удаление фильма

# Фильтры и сортировка 
Доступные параметры:

order_by поле, по которому выполняется сортировка

limit  количество фильмов, отображаемых в ответе

offset  пропуск указанного количества записей


# Модель Даннынх

Для каждого фильма предусмотрены следующие поля:

id 

title 

genre 

rating 

year 


# Ограничения
Для фильма есть ограниченичя

Название - обязательное текстовое поле

Жанр  - текстовое поле с указанием жанра фильма

Рейтинг - числовое значение, с диапазоном 1-10

Год выпуска - целое число
